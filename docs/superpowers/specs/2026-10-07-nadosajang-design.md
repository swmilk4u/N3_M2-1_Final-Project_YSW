# 나도사장 MVP 설계

2026-10-07. 기획서와 사람인 UX를 바탕으로 저장한 창업 아이디어를 공고별 지원서에 재사용한다. 화면에 시연용 표시를 붙이지 않는다. 정부 공고 수집과 RAG는 후속 연동이다.

사용자 제공 `20261017 와이어프레임_v1`의 실제 화면 HTML을 확인했다. 홈의 준비 도구, 프로필 단계 입력, 10개 영역의 아이템 프로필, 왼쪽 필터와 세로 공고 목록, 공고 상세, 왼쪽 문항·가운데 편집·오른쪽 점검의 PSST 작업실을 반영한다. 저장 HTML에 실내용이 없는 라운지는 후속 범위이며, 지원 현황은 세 상태의 보드로 구현한다.

주요 흐름: 홈 → 프로필 입력 → 아이디어 저장·10개 영역 보완 → 공식 공고 검색·필터·상세·스크랩 → 저장한 아이디어로 PSST 네 문항 구성 → 수정·저장·복사·TXT 내보내기 → 지원 상태 관리.

브랜드: 파란색 #2F5BD3, 중성 배경 #F4F5F7, 흰 패널과 14px 모서리. 모바일에서는 단일 열로 전환한다. 화면 구조는 와이어프레임을 반영하되 실제 동작이 없는 AI 분석 점수나 개인정보 약속은 표시하지 않는다.

구조: 모듈형 HTML/CSS/JS, 저장 API, 로컬 파일·배포 D1. 공고는 출처와 확인일이 있는 공식 원문 스냅샷이다. 실제 LLM·RAG·HWP 양식 변환·외부 기관 제출·회원별 데이터 분리는 후속 범위다. 초안은 사용자 입력을 배치하며 없는 실적을 생성하지 않는다. 사업성 진단과 입력 완성도를 구분한다.

검증: 도메인과 API 단위 테스트, 독립 코드 리뷰, 브라우저의 프로필·아이디어·공고·초안·저장·새로고침·내보내기·현황 및 모바일 흐름을 확인한다. 연속 입력의 저장 응답 순서와 긴 입력의 문항 한도를 별도로 회귀 검증한다.
