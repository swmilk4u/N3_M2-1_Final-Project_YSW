# AI지원서 구현 점검
점검일: 2026-10-07
기준: 제공된 와이어프레임의 AI 지원서 작성 화면(saved_resource(10).html).

## 명칭과 현재 구현
메뉴, 페이지 제목, 편집 화면 상단 이름을 AI지원서로 통일했습니다.

| 와이어프레임의 흐름 | 현재 구현 |
| --- | --- |
| 공고·아이디어 선택 | 관심 공고에서 저장한 아이디어를 선택 |
| 초안 작성 | 창업자 정보·아이디어·공고를 공통 PSST 4문항으로 구성 |
| 불러온 재료 | 아이디어와 경력 정보 표시, 아이디어 수정 화면 연결 |
| 문항별 편집 | 직접 수정, 문항 이동, 완료 표시 |
| 글자 수 | 공백 포함·미포함 실시간 계산, 문항당 15,000자 저장 한도 |
| 자동 저장 | 입력 후 저장, 새로고침 복원, 수정본을 덮어쓰지 않고 다시 열기 |
| 문항 점검 | 입력 여부와 대괄호 보완 문구 개수 확인 |
| 내보내기 | 문항·전체 복사, 전체 TXT 다운로드 |
| 준비 현황 | 작성 중·검토 중·제출 완료 상태 관리 |

완료한 문항에 체크리스트를 추가해 내용이 바뀌면 완료 표시를 해제하도록 수정했습니다.

## 아직 연결하지 않은 기능
- 생성형 AI 모델을 통한 초안 작성·재작성·분량 조절·구체화·표 변환
- 실제 공고 첨부 양식의 문항·글자 수·평가기준 자동 추출
- 문항 간 일관성, 사업성, 내용 품질을 판단하는 AI 평가
- 원본 양식을 유지하는 HWP·DOCX·PDF 출력과 팀원 공동 편집

현재 초안은 저장된 내용을 배치하는 방식이며, 실제 LLM 호출이나 RAG 검색 결과가 아닙니다. 공통 작성 안내는 실제 공고의 지정 문항과 분량을 대신하지 않습니다. 시장 규모·매출·실적 등을 자동으로 만들어 넣지 않습니다.

## 검증
PC·모바일에서 초안 구성, 직접 수정, 글자 수 계산, 자동 저장·새로고침 복원, 문항 이동·완료 표시, 체크리스트 추가 시 완료 해제, 문항 복사와 TXT 다운로드, 같은 공고·아이디어의 기존 수정본 보존을 확인했습니다. 검증에는 별도의 임시 저장소를 사용했습니다.

## AI 연동 시 이어갈 위치
- src/client/domain.js: 공통 PSST 초안 구성
- src/client/app.js: 초안 생성과 문항 편집 동작
- src/server/: 모델 호출·RAG·양식 분석 API를 추가할 위치
- src/client/views.js: 문항 안내와 편집·검토 화면

API 키는 서버 환경 변수에 두고, 공고의 실제 문항·분량·출처와 사용자 수정본을 함께 관리하는 구조로 확장합니다.
