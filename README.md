# 나도사장

창업자 정보를 한 번 정리하고, 지원사업 공고별 지원서 준비에 재사용하는 웹 MVP입니다. 사용자 제공 기획서와 `20261017 와이어프레임_v1`의 저장 HTML을 기준으로 구현했습니다.

## 바로 실행

Node.js 22 이상이 설치된 상태에서 이 폴더의 터미널을 여세요. 기본 실행에는 패키지 설치가 필요 없습니다.

```powershell
npm start
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. 프로필·아이디어·지원서·스크랩은 `.local/state.json`에 저장되어 서버를 다시 실행해도 유지됩니다. 기존 저장 파일을 지우면 로컬 작업실도 초기화됩니다.

```powershell
npm test
npm run build
```

## 사용할 수 있는 흐름

1. 마이페이지에서 지역·창업 단계·분야·경력을 입력합니다.
2. MY아이디어에서 이름과 설명을 저장하고, 고객·문제·시장·제품·수익·재무·팀 등 10개 영역을 보완합니다. TXT 메모를 가져올 수도 있습니다.
3. 공고를 검색하고 지역·단계·분야·지원 유형·마감일로 필터링하거나 스크랩합니다. 상세 화면에서 신청 조건·지원 내용·원문 양식을 확인합니다.
4. 관심 공고에서 아이디어를 선택하면 PSST 네 문항의 초안이 만들어집니다. 문항별로 편집·자동 저장·완료 표시·복사·텍스트 다운로드를 할 수 있습니다.
5. 지원 현황에서 작성 중·검토 중·제출 완료 상태를 직접 관리합니다. 같은 공고와 아이디어로 다시 시작하면 기존 수정본을 열어 덮어쓰지 않습니다.

## 현재 구현 범위

- 공고는 공식 기관 원문을 확인한 6건의 스냅샷입니다. 확인일은 2026-10-07이며, 자동 수집·갱신은 아직 연결하지 않았습니다.
- 초안은 저장한 입력과 공고 내용을 PSST 구조에 배치합니다. 실제 LLM 호출이나 RAG 검색 결과는 아닙니다. 입력하지 않은 실적이나 시장 수치를 만들지 않습니다.
- 아이디어 점검은 입력 여부를 계산합니다. 사업 타당성이나 선정 가능성 점수로 해석하지 않습니다.
- 긴 입력은 초안에 앞부분과 보완 안내를 불러오며, 전체 원문은 아이템 프로필에 보존합니다. 지원서 문항은 15,000자까지 저장합니다.
- 내보내기는 TXT·복사입니다. HWP/DOCX 지정 양식 변환, 외부 기관 접수, 결제, 라운지와 파일 첨부 분석은 후속 범위입니다.
- 배포 저장소는 D1이며, 현재 작업실은 소유자 한 명을 기준으로 합니다. 회원별 저장소 분리와 인증을 구현하기 전에는 공개 서비스로 운영하지 않습니다.

## 후속 연동 위치

| 파일 | 역할 |
| --- | --- |
| `src/client/notices.js` | 공고 데이터·출처. 추후 수집/RAG API로 교체 |
| `src/client/domain.js` | 조건 비교·입력 점검·PSST 초안 구성 |
| `src/client/app.js` | 화면 이동·사용자 동작·자동 저장 |
| `src/client/views.js` | 홈·프로필·아이디어·공고·편집·현황 화면 |
| `src/server/api.mjs` | 저장 API와 revision 충돌 처리 |
| `src/server/worker.mjs` | 배포용 Worker와 D1 저장 |
| `scripts/dev.mjs` | 로컬 HTTP 서버와 파일 저장 |
| `scripts/build.mjs` | 배포 산출물 생성 |
| `db/schema.ts`, `drizzle/` | D1 스키마와 생성된 마이그레이션 |

LLM/RAG는 서버에 연동하고, API 키는 브라우저 코드에 넣지 않습니다. 검색한 원문의 출처·확인일·대상 양식을 함께 반환하도록 확장하면 됩니다. 현재 초안과 사용자가 수정한 지원서는 별도로 보존하는 흐름을 유지하세요.

## 검증

도메인·API 단위 테스트와 실제 브라우저 검증을 수행했습니다. 프로필 입력, 아이디어 편집, 공고 검색·스크랩, 초안 생성, 연속 입력 자동 저장, 새로고침 복원, 문항 이동, 상태 변경과 TXT 내보내기를 확인했습니다. 1440px·390px 화면에서 주요 경로의 가로 넘침을 점검했습니다. QA 데이터는 별도 임시 저장 파일을 사용하며 배포 데이터에는 포함되지 않습니다.

과제 전체를 완료하려면 실제 생성형 AI와 RAG 연동, 사용자 5명 이상 테스트 및 결과 정리가 추가로 필요합니다.
