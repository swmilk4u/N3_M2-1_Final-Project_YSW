# 나도사장

**내 창업 아이디어를 저장하고, 공고 찾기부터 지원서 준비까지 이어가는 웹서비스**입니다. 아이디어와 창업자 정보를 한곳에 정리해 지원사업 공고마다 재사용합니다.

## 주요 기능

- **마이페이지:** 지역·창업 단계·분야·경력 등 창업자 정보 관리
- **MY아이디어:** 고객·문제·해결책·시장·수익·팀 등 기존 작업 목록, 새 아이디어 작성, 샘플 복사 및 SWOT·TAM·SAM·SOM 작성 가이드
- **공고 찾기:** 지원사업 검색, 조건 필터, 스크랩 및 공식 원문 확인
- **지원서 작성:** 저장한 아이디어를 PSST 구조의 초안으로 구성하고 문항별 편집·자동 저장·내보내기
- **지원 현황:** 작성 중·검토 중·제출 완료 상태 관리

## 서비스 구조

| 영역 | 구성 |
| --- | --- |
| 화면 | 홈, 마이페이지, MY아이디어, 공고 목록·상세, 지원서 편집, 지원 현황 |
| 프런트엔드 | HTML·CSS·JavaScript 기반 화면과 사용자 동작 처리 |
| 서버·저장소 | Cloudflare Worker의 저장 API와 D1 데이터베이스 |
| 지원서 구성 | 창업자 정보 + 사업 아이디어 + 공고 내용을 PSST 초안에 반영 |

PSST는 문제인식(Problem), 실현가능성(Solution), 성장전략(Scale-up), 팀 구성(Team)을 뜻합니다.

## 향후 고도화

현재 공고는 공식 원문을 확인한 데이터이며, 지원서 초안은 저장한 내용을 공통 구조에 배치하는 방식입니다. 정부 지원사업 공고 수집·RAG 검색, 생성형 AI 초안 작성, 공고별 지정 양식 대응을 순차적으로 연결할 예정입니다.

현재 작업실은 공유 저장소를 사용합니다. 회원 인증과 사용자별 데이터 분리도 후속 구현 범위입니다.
